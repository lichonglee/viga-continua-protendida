# Viga contínua protendida, 2 vãos

Projeto didático de concreto protendido (UnB): viga contínua de 2 × 10 m, seção 30 × 90 cm, C30, CAA II, pós-tração aderente, CP190 RB Ø12,7.
Contém o motor de cálculo em Python, a planilha de apoio (14 abas), memorial, desenhos DXF, app interativo (HTML), slides e roteiros.

Leia o `CLAUDE.md` para convenções, valores de referência e mapa dos arquivos. Para continuar o trabalho com o Claude Code, abra o terminal na raiz do repositório e rode `claude`.
